# Pokémon Sun and Moon AP Manual
A Manual Randomizer for Pokémon Sun and Moon for use with the [Archipelago Manual](https://github.com/ManualForArchipelago) Project. This Manual includes checks for all ground items, Ride Pokemon, Trial Badges (Client only items), Grand Trial Stamps, Z-Crystals and items given by important characters. Options are included to add hidden items, optional NPCs items, and items that may involve editing your game's save with PKHeX. Two different Goal options are available as well, including a sync viable one to Defeat Olivia. The latest stable release of the Manual AP World being in your Custom Worlds folder is required for this to work as expected.

[PKHeX](https://github.com/kwsch/PKHeX) is NOT required to use this AP World, but can help provide a smoother experience and allow you to add more checks to the game.

Logic Requirements can be found on this game's thread in the Manual for Archipelago Discord server. A detailed PKHex tutorial can be found on my [XY Manual](https://github.com/Snifit57/PokemonXYAPManual) Github page.
